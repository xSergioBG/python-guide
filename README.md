## Uso

Abre un tema y revisa sus instrucciones y archivos antes de ejecutar el ejemplo. Los capítulos pueden usar dependencias distintas; no existe una instalación única para toda la guía.

Para trabajar con un ejemplo, usa un entorno virtual y conserva sus requisitos específicos. No ejecutes todos los scripts en bloque: algunos ejemplos trabajan con archivos, red o bases de datos.

## Alcance

Material educativo. No se ha confirmado compatibilidad de todos los capítulos con una misma versión de Python ni una suite de validación común.
